最終更新: 2026-07-26

本アプリ「Genshin Builder」は非公式のファン向けツールです。miHoYo / HoYoverse とは関係ありません。

## 収集する情報

### 端末内のみで扱う情報

育成進捗、ブックマーク、目標、設定などは端末内のローカルデータベースに保存されます。運営者サーバーへのクラウドバックアップは現在提供していません。

### HoYoLAB 連携（任意）

ユーザーが明示的に連携を開始した場合のみ、HoYoLAB / HoYoverse のサービスへ認証情報（Cookie 等）および UID・リージョン等が送信されます。認証情報は端末の Secure Storage に保存し、運営者サーバーへ送信・保存しません。

連携前にアプリ内で説明画面を表示し、同意後にのみログインを開始します。

## 共有・販売・広告

運営者はユーザーデータを第三者へ販売しません。広告 SDK・行動解析 SDK・クラッシュ解析 SDK は現在使用していません。

## 通信の暗号化

外部通信は HTTPS を使用します。

## 削除

設定画面から次を実行できます。

- HoYoLAB 連携解除（Cookie / 認証情報の削除）
- ローカル育成データの削除
- アプリ設定の初期化（同意記録を含む。重大変更時は再確認が必要）

## ホスティングログ

運営者の API ホスティング提供者がアクセスログ（IP、User-Agent 等）を保持する場合があります。詳細な保存期間はホスティング設定の確認が必要です。
